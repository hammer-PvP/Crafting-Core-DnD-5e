# Crafting Core v0.0.2 — Live Test Checklist

## Regression: v0.0.1 crafting cycle

- [ ] Module activates normally on Foundry 14.365 / D&D5e 5.3.3.
- [ ] GM-only Crafting Core button still appears in the Items Directory.
- [ ] Existing v0.0.1 recipes remain visible and editable.
- [ ] A Character that already knows a recipe still sees it in the Crafting tab.
- [ ] Crafting still consumes requirements and creates the final Item.
- [ ] Player → active GM crafting request still works.

## Character Sheet UX

- [ ] Crafting tab remains immediately after Effects and before Biography.
- [ ] Recipe dropdown shows `N× Recipe Name` for every learned recipe.
- [ ] A recipe with insufficient materials shows `0×` but remains selectable.
- [ ] Recipe Builder sidebar active selection is aligned and scrollbar no longer visually crowds the rows.

## Knowledge Item icons

- [ ] New Recipe defaults to `icons/sundries/documents/document-gold.webp`.
- [ ] Formula defaults to `icons/sundries/scrolls/scroll-bound-leather-tan.webp`.
- [ ] Manual defaults to `icons/sundries/books/book-tooled-silver-blue.webp`.
- [ ] Blueprint defaults to `icons/commodities/tech/blueprint.webp`.
- [ ] Changing the knowledge type updates the image while it is still using a default icon.
- [ ] A manually customized knowledge image is not replaced when changing other recipe fields.
- [ ] Browse Image opens in Core Data `icons/`.

## Material Catalog

- [ ] `Material Catalog` button opens from the Crafting Core GM app.
- [ ] `Create / Sync Materials` creates `Crafting Core — Materials` as a world Item Compendium.
- [ ] Generated entries are Item type `loot` and subtype `Trade Good` (`system.type.value = trade`).
- [ ] Generated entries use the agreed bag icon by default.
- [ ] Common / Rare / Legendary rarity is written to the Item.
- [ ] Default price values are written according to the Material Catalog settings.
- [ ] Crafting Core metadata flags contain stable material ID, family, nature, rarity, chance, and quantity formula.
- [ ] Running Sync a second time does not duplicate managed materials.
- [ ] Changing a managed material's icon/name/description and syncing again preserves that presentation edit.
- [ ] Changing rarity price defaults and syncing updates catalog-managed prices.
- [ ] Dragging an existing Item to Register Existing Item copies it into the Materials Compendium as a Trade Good.
- [ ] A registered custom material is not duplicated by normal built-in catalog sync.
- [ ] Items can be dragged directly from the Materials Compendium into Recipe Builder requirements.

## Frozen output snapshot

- [ ] Create a recipe whose output has Activities/Effects/flags.
- [ ] Craft it and confirm the produced Item keeps those structures.
- [ ] If practical, delete/move the original source after saving the recipe and confirm the recipe can still reproduce its stored output snapshot.

## Not part of v0.0.2

- Actor Compendium scanner / automatic Harvest Profiles.
- Token HUD harvest button.
- Item Piles corpse conversion/injection.
- Biome Gathering generator.
- Region/vendor generation.
