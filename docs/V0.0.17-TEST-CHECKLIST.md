# Crafting Core v0.0.17 — Live Test Checklist

Use v0.0.16 behavior as the comparison baseline. Token Harvest remains explicit GM-only.

## 1. Remove All — regression
- Set Existing NPC Loot to **Remove All Existing Items**.
- Harvest a dead profiled NPC with physical gear.
- Confirm the pile contains only Crafting Core Harvest / Essence / Pinpoint loot.
- Confirm there is no regression from v0.0.16.

## 2. Keep All — regression
- Set **Keep All Existing Items**.
- Harvest the Deva or another NPC with a unique/stat-block weapon.
- Confirm the original Item remains once (for example Holy Mace x1) and Crafting Core materials are appended.

## 3. Keep Physical — duplication fix
- Set **Keep Physical Gear / Remove Natural & Features**.
- Harvest the Deva. Confirm **Holy Mace x1**, not x2.
- Test an NPC with Scimitar + Leather Armor. Confirm original quantities are not doubled.
- Confirm natural weapons/features do not appear as loot.

## 4. Normalize — equivalent-item duplication fix
- Configure PHB/SRD normalization sources.
- Harvest Bugbear Warrior. Expected physical loot: **Hide Armor x1** and **Light Hammer x3**, plus generated Crafting Core materials.
- Confirm Light Hammer is the official/base version rather than the 3d4 stat-block variant.
- Harvest Deva. Confirm **Holy Mace -> Mace x1**.
- Harvest the tested Bullywug. Confirm its special Rapier becomes **Rapier x1**.

## 5. Firearm Homebrew
- Enable **Convert Firearms to Random Crossbows** and keep mode on Normalize.
- Harvest several NPCs carrying Firearm weapons.
- Confirm each Firearm stack becomes exactly one of: Hand Crossbow, Light Crossbow, Heavy Crossbow.
- Confirm the source stack quantity is preserved.
- Repeat several times to confirm the result can vary.
- Switch to Keep All / Keep Physical and confirm the homebrew does not convert firearms outside Normalize.
- Disable the homebrew and confirm Normalize no longer forces Firearm -> Crossbow conversion.

## 6. Multi-select / corpse integrity
- Select several eligible dead Tokens and harvest together.
- Confirm each corpse remains at its original position/appearance and receives its own loot.
- Confirm already-harvested Tokens cannot be harvested twice.
