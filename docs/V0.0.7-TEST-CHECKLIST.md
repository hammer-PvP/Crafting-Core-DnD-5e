# Crafting Core v0.0.7 — Live Test Checklist

Target: Foundry VTT 14.365 + D&D5e 5.3.3.

## 1. Regression / launcher

- Open the Item Directory and confirm `Crafting Core` + `Generate` launchers still work.
- Open Crafting Core and confirm existing Recipes, Material Catalog, Generate Materials, Learn Sources, Character crafting, and v0.0.6 rarity behavior remain intact.
- Confirm the Recipe sidebar is visibly wider and the 2×2 GM tool block leaves more vertical space for Recipes.

## 2. Creature Scanner sources

- Open `Crafting Core → Creature Scanner`.
- Confirm only Actor Compendiums are offered as scan sources.
- Select one small monster/NPC pack first.
- Click `Scan Selected Compendiums` and verify progress updates.
- Confirm source Actors and source Compendium contents remain unchanged.

## 3. Profile creation / review

- Confirm scanned NPCs appear as Harvest Profiles with image, creature type, CR, anatomy summary, automatic slot count, and Pinpoint count.
- Use search and Creature Type filter.
- Open several profile editors.
- Confirm no profile contains more than four automatic slots.

## 4. Anatomy sanity cases

Use equivalent creatures available in your packs:

- Skeleton-like Undead: should infer `bone`; should not infer `flesh` or `incorporeal`; should never auto-select `Undead Flesh`.
- Zombie/Ghoul-like Undead: should infer physical flesh/blood/bone; should not auto-select Ectoplasm.
- Ghost/Specter/Wraith-like Undead: should infer `incorporeal`; should not infer flesh/bone.
- Griffon/feathered clawed Monstrosity: attack/feature names should be able to infer claw/beak/feather when present in Actor data.
- Ooze: should infer `amorphous`.
- Plant creature: should infer `plant`.
- Construct: inspect whether its name/data sensibly resolves flesh, mineral/crystal, metal/mechanical, or conservative generic construct anatomy.

## 5. High-tier slot

- A normal/low-tier Actor should target Very Rare for slot 4 when a compatible Very Rare material exists.
- An Actor with CR 17+, Legendary Actions, Legendary Resistance, or Lair data should target Legendary for slot 4 when a compatible Legendary material exists.
- Empty high slots are valid when no material satisfies the Actor anatomy.

## 6. GM editing

- Change one automatic slot Material.
- Change that slot's chance and quantity formula.
- Edit the comma-separated Anatomy Tags field.
- Save and reopen the profile; confirm edits persist.

## 7. Pinpoint Overrides

- Add a Pinpoint Override.
- Choose a registered Crafting Core material, set chance to 100%, and set a quantity/formula.
- Save and reopen; confirm it persists and does not replace any of the four automatic slots.
- Reanalyze the same Actor; confirm automatic anatomy/slots rebuild while the Pinpoint Override remains.
- Remove the Pinpoint Override and save.

## 8. Profile lifecycle

- Reanalyze one profile from the scanner list and confirm it refreshes from the source Actor.
- Delete one Harvest Profile and confirm only Crafting Core metadata disappears; the source Actor remains untouched.
- Rescan the source pack and confirm the deleted profile is rebuilt.

## 9. Console

During all tests, watch for `dnd5e-crafting-core` errors. If the scanner reports a failed Actor, copy the exact console error plus the Actor/pack name for a surgical fix.
