# Crafting Core v0.0.11 — Test Checklist

## Prerequisites
- Foundry VTT 14.365.
- D&D5e 5.3.3.
- Item Piles active for corpse tests.
- At least one scanned/reanalyzed Harvest Profile.
- Crafting Core materials synchronized.

## 1. Creature Scanner scroll regression
1. Open Creature Scanner with enough stored Harvest Profiles to exceed the visible window height.
2. Confirm the Harvest Profile list scrolls vertically while the Scanner header, source summary, filters, and Scan controls remain fixed.
3. Search/filter the list and confirm scrolling still works after rerender.

## 2. Configure normalization priority
1. Open **Game Settings → Crafting Core**.
2. Under **Existing NPC Loot**, choose **Normalize from Compendiums**.
3. Select one Item Compendium as priority #1 (recommended live test: PHB 2024).
4. Select another as priority #2 (recommended fallback: SRD 5.2).
5. Confirm no more than four Item Compendiums can be selected.
6. Reorder selected sources and save. Reopen Settings and confirm order persists.

## 3. Modified common weapon normalization
1. Use a dead scanned NPC with a physically modified common weapon, e.g. a `Light Hammer` whose NPC version deals 3d4.
2. Generate Harvest from the Token HUD.
3. Confirm the corpse becomes an Item Pile.
4. Confirm the NPC's modified Light Hammer is gone.
5. Confirm the pile contains the clean base Light Hammer from the highest-priority configured Compendium that contains a safe match.
6. Confirm the base Item's normal damage/data is used, not the NPC stat-block damage.

## 4. Priority fallback
1. Use an Item that is absent from source #1 but present in source #2.
2. Harvest the corpse.
3. Confirm source #2 supplies the normalized Item.
4. If the same base Item exists in #1 and #2, confirm #1 wins.

## 5. Natural / feature / unique Item removal
1. Use an NPC containing natural attacks or mechanics such as Grab, Bite, Claw, Brute, special Actions/Features, or a uniquely named monster weapon.
2. Harvest in Normalize mode.
3. Confirm Features/Spells/non-physical Items are absent.
4. Confirm natural weapons are absent.
5. Confirm a uniquely named physical Item with no safe base Compendium match is absent.
6. Confirm Crafting Core generated materials remain present.

## 6. Existing quantity
1. Give an NPC two copies/quantity 2 of a normalizable physical Item.
2. Harvest it.
3. Confirm the normalized base Item is added with quantity 2, not quantity 1 or multiplied twice.

## 7. Empty material Harvest with real gear
1. Use a profile whose material chances can all fail, on an NPC with at least one normalizable physical Item.
2. Generate Harvest until the Crafting Core material result is empty.
3. Confirm the corpse can still become an Item Pile because normalized gear exists.
4. Confirm anti-reroll harvested metadata is still written.

## 8. Other loot handling modes
- **Remove All Existing Items**: only Crafting Core generated Harvest remains.
- **Keep Physical Gear / Remove Natural & Features**: ordinary physical NPC Items remain as-is; non-physical and structurally natural weapons are removed.
- **Keep All Existing Items**: v0.0.10-style preservation remains available intentionally.

## 9. Regression
- Essence manual generation remains unchanged.
- Scanned Actor Essence generation remains unchanged.
- Pinpoint materials remain separate and are retained.
- Multi-token Harvest still creates one pile per eligible corpse.
- A corpse can still only be harvested once.
- Item Piles disabled: Crafting Core loads normally and Token Harvest controls remain unavailable.
