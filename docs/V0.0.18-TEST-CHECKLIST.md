# Crafting Core v0.0.18 — Live Test Checklist

Use v0.0.17 as the stable baseline. This build changes Recipe/Crafting resolution only; Harvest and corpse-loot behavior should be identical to v0.0.17.

## 1. Legacy Recipe regression
- Open an existing Recipe created before v0.0.18.
- Confirm **Require a Crafting Check** is disabled by default.
- Learn/craft it with a Character that has the required ingredients.
- Confirm it consumes the full ingredients and creates the output exactly as v0.0.17 did.

## 2. Anyone may attempt / no proficiency
- Configure a Recipe with a Crafting Check (for example Arcana DC 15), **Anyone**, **Roll Normally**.
- Use a Character without Arcana proficiency.
- Confirm **Attempt Craft** opens the native D&D5e Arcana roll on that player's client.
- On a successful total, confirm full materials are consumed and the output is created.

## 3. Proficient = Automatic Success
- Configure Smith's Tools (or another known Tool) as Relevant Proficiency.
- Set **Anyone** + **Automatic Success** + a Crafting Check.
- Test with a proficient Character: confirm no final roll is requested and crafting succeeds.
- Test with a non-proficient Character: confirm the configured Crafting Check is required.

## 4. Requires proficiency
- Configure one relevant Skill/Tool and set **Requires relevant proficiency**.
- Confirm a non-proficient Character cannot press Craft and the sheet explains the requirement.
- Confirm a proficient Character can proceed.
- Configure two proficiencies and test both **Any one qualifies** and **Both are required**.

## 5. Check picker coverage
- Test at least one Ability Check, Skill Check, Tool Check, and Saving Throw.
- Confirm each uses the native D&D5e 5.3.3 roll dialog/card and the configured DC.
- Confirm the player can cancel the roll without consuming materials.

## 6. Failed roll — no material loss
- Enable a Crafting Check and disable **Lose materials on failure**.
- Force/fail the check.
- Confirm no output is created, no crafting job starts, and all ingredients remain.

## 7. Failed roll — percentage loss
- Enable material loss and set 50%.
- Use quantities that make rounding visible (for example 3 common materials + 1 Essence).
- Fail the check.
- Confirm 3 -> 1 remaining (2 lost) and 1 Essence -> 0 remaining (1 lost).
- Repeat at 25%, 100%, and 0% if desired.

## 8. Anti-replay / GM authority
- Confirm the failed or successful Crafting Check chat card cannot be reused by clicking Craft again; a new attempt must make a new roll.
- Confirm inventory/output mutation happens only after the active GM validates the request.

## 9. Harvest regression smoke test
- Harvest one normal dead profiled NPC and one Normalize/Homebrew Firearm case previously validated in v0.0.17.
- Confirm corpse loot, Essence, quantities, and Firearm -> random Crossbow behavior are unchanged.
