# Crafting Core v0.0.15 — Test Checklist

## Priority live regression

Use fresh dead Tokens from Actors that already have valid Harvest Profiles.

### 1. Normalize from Compendiums
- Configure PHB 2024 as normalization source #1 and SRD 5.2 as #2.
- Harvest a fresh Bugbear Warrior.
- Confirm the original corpse is replaced only after the new pile is populated.
- Confirm all successful Crafting Core material rolls are present, not only one Item.
- Confirm normalizable physical gear uses the base Compendium version.
- Confirm natural/stat-block Features do not appear.
- Confirm unmatched unique physical gear is discarded.

### 2. Remove All Existing Items
- Harvest another fresh eligible corpse.
- Confirm no original NPC gear/features survive.
- Confirm every successful Harvest/Essence/Pinpoint result is present.

### 3. Keep Physical Gear / Remove Natural & Features
- Confirm physical gear from the NPC remains unchanged.
- Confirm natural weapons and Features are absent.
- Confirm Crafting Core generated materials are added in addition to retained gear.

### 4. Keep All Existing Items
- Confirm all Item Piles-transferable NPC Items remain.
- Confirm generated Harvest is added in addition to them.

## Multi-item and quantity validation
- Test a profile/result where at least two physical/material slots succeed.
- Confirm all distinct results appear in the pile.
- Confirm stack quantities match the generation result.
- Confirm duplicate/stack quantities are not multiplied or reset to 1.

## Corpse artwork
- Confirm the new pile keeps the original Token image, size, position, rotation and scale.
- Confirm a one-item loot result does not change the corpse image into that Item's icon.

## Transaction safety
- No original corpse should disappear before the pile is fully populated.
- If an incomplete pile is detected, Crafting Core should roll it back and leave the original corpse intact.
- No successful corpse should be harvestable twice.

## Existing regressions
- Creature Scanner profile list still scrolls.
- Manual Creature Harvest Essence Affinity still works.
- Batch Harvest still processes each selected dead eligible Token independently.
