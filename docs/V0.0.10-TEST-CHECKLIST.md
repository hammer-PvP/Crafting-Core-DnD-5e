# Crafting Core v0.0.10 — Test Checklist

## Prerequisites
- Foundry VTT 14.365.
- D&D5e 5.3.3.
- Crafting Core materials synchronized with **Materials → Create / Sync Materials**.
- Item Piles active for Token Harvest tests (and the D&D5e Item Piles support/profile required by your Item Piles installation, if applicable).
- At least one Actor source scanned/reanalyzed in Crafting Core v0.0.9+ so its Harvest Profile contains Essence analysis.

## 1. Manual Creature Harvest — no affinity
1. Open **Generate Materials**.
2. Choose **Creature Harvest**.
3. Leave every **Essence Affinity** checkbox empty.
4. Generate repeatedly.
5. Confirm normal physical materials still follow the selected Creature Type/Profile.
6. Confirm the Essence result is approximately 50% **Arcane Essence** and 50% no Essence over many rolls.
7. Confirm **Create Loot Folder** materializes the exact preview without rerolling.

## 2. Manual Creature Harvest — one affinity
1. Select only **Fire**.
2. Generate repeatedly.
3. Confirm Essence results are only **Arcane Essence** or **Flame Essence**.
4. Confirm the long-run target is approximately 45% Arcane / 55% Flame.

## 3. Manual Creature Harvest — multiple affinities
1. Select **Fire** and **Lightning**.
2. Generate repeatedly.
3. Confirm the 55% specific share is distributed between Flame and Lightning Essence.
4. Confirm no unrelated specific Essence appears.

## 4. Token HUD eligibility
Prepare four Tokens:
- dead + scanned profile;
- alive + scanned profile;
- dead + no profile;
- dead + already harvested (after completing section 5 once).

Confirm the `icons/svg/item-bag.svg` Harvest control is only useful when at least one selected Token is currently eligible.

## 5. Single-corpse Item Piles Harvest
1. Kill/set to 0 HP one Token whose Actor resolves to a scanned Harvest Profile.
2. Right-click the Token.
3. Click the small bag **Generate Harvest** control.
4. Confirm the exact Actor Harvest Profile is rolled: physical slots, Essence slot, and Pinpoint Overrides.
5. Confirm the corpse Token is converted into an Item Pile rather than creating a second automatic harvest chest.
6. Confirm generated Crafting Core Items are added with correct quantities.
7. As a player, open the pile and loot the generated materials.
8. Confirm clicking Harvest again cannot generate a second harvest from the same Token.

## 6. Empty corpse harvest
1. Use a profile/chances capable of producing no successful material.
2. Generate Harvest.
3. Confirm no empty Item Pile is created solely for the empty result.
4. Confirm the corpse is marked harvested and cannot be rerolled.

## 7. Multiple selected corpses
1. Select several Tokens including eligible dead creatures and at least one ineligible Token.
2. Open the Token HUD on one selected Token.
3. Click **Generate Harvest for Selected**.
4. Confirm each eligible corpse is rolled independently against its own stored profile.
5. Confirm each successful corpse becomes its own Item Pile.
6. Confirm alive/no-profile/already-harvested Tokens are skipped rather than aborting the batch.
7. Confirm the GM notification summarizes generated/skipped results without chat spam.

## 8. Safety / regression
- Disable Item Piles and reload: Crafting Core still loads; Token Harvest control is absent.
- Manual material generation still works without Item Piles.
- Environment Gathering is unchanged.
- Creature Scanner / Reanalyze is unchanged.
- Existing Pinpoint Overrides still roll outside automatic slots.
- Existing v0.0.9 Harvest Profiles continue to work.
- Character Crafting tab / Recipes / Knowledge are unchanged.
