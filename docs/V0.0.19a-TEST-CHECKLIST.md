# Crafting Core v0.0.19a — Material Icon Curation Test Checklist

This build is intentionally visual/catalog-focused. The v0.0.19 Crafting Projects runtime and the validated Harvest pipeline should behave exactly as before.

## Upgrade / migration

- Install v0.0.19a over a world that already has `Crafting Core — Materials` from v0.0.19.
- Confirm the world loads without errors.
- Confirm managed materials that still used the generic brown pouch are automatically assigned their curated v0.0.19a default icons.
- Confirm a managed material whose image had been manually changed to a non-default icon keeps that image.
- Confirm no new Materials Compendium is created automatically in a world that never created one.

## Materials catalog layout

- Open **Crafting Core → Materials**.
- Confirm the window opens wider than v0.0.19 and remains resizable.
- Confirm each group header still communicates its source/category, e.g. `Creature Harvest — Aberration`.
- Confirm the redundant per-row **Nature** column is gone.
- Confirm Rarity, Chance, Qty, icon choices, and Edit remain readable without horizontal overlap at the default window size.
- Confirm filters/search still work.

## Three-candidate curation

For several groups (at minimum Aberration, Beast, Construct, Essence, Gathering Mineral, and Profession & Trade):

- Confirm every built-in row shows exactly **three** icon previews.
- Confirm exactly **one** candidate is preselected.
- Confirm `Aberrant Eye` offers eye-themed candidates; `Psychic Gland` / `Neural Fragment` brain/psionic candidates; ores use ore/stone art; ingots use metal ingots; etc.
- Hover candidates and confirm the tooltip exposes the native `icons/...` path for GM inspection.

## Selecting icons

- Select candidate 2 on a material.
- Confirm the row's main preview changes immediately without the catalog jumping back to the top.
- Close and reopen Materials; confirm candidate 2 remains selected.
- Open `Crafting Core — Materials`; confirm the Compendium Item uses the chosen image.
- Select candidate 3 and repeat.
- Confirm choosing icons does not change rarity, chance, quantity, tags, anatomy requirements, biomes, price, or material identity.

## Existing custom/manual presentation

- Manually assign a non-default image to a managed material through the existing Material Editor or Compendium.
- Reopen Materials and confirm that current image is preserved as one of the three visible choices.
- Run **Create / Sync Materials** and confirm the non-default image remains intact.
- Use **Reset Curated Default** and confirm it deliberately returns to the curated v0.0.19a default.

## Regression checks

- Generate Creature Harvest from an existing validated Harvest Profile and confirm material IDs/results are unchanged.
- Generate Environment Gathering and confirm its existing pools/results are unchanged.
- Start/work/cancel/finish a v0.0.19 Crafting Project and confirm Project behavior is unchanged.
- Confirm Knowledge Sources and Recipe crafting still resolve materials after icon changes.
- Confirm Item Piles corpse harvesting and gear normalization remain unchanged.

## Pass condition

v0.0.19a is satisfactory when the catalog can be curated visually across long lists without scroll jumps or lost selections, all 132 curated materials expose three logical candidates with one default, the Compendium reflects the chosen path, and no v0.0.19 mechanics regress.
