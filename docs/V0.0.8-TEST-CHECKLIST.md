# Crafting Core v0.0.8 — Live Test Checklist

Target: Foundry VTT 14.365 + D&D5e 5.3.3.

## 1. Game Settings → Crafting Core

- Open **Game Settings → Configure Settings** and locate **Crafting Core**.
- Open **Configure Crafting Core**.
- Confirm sources are shown at the package/source level rather than as every internal Compendium.
- Confirm a module such as Monster Manual reports how many compatible Actor packs it contains.
- Confirm World Actor Compendiums appear individually.
- Select at least two sources, reorder them with the priority arrows, save, reopen, and confirm selection/order persist.

## 2. Creature Scanner source UI

- Open **Crafting Core → Scanner**.
- Confirm the old large Compendium checkbox list is gone.
- Confirm the compact source summary shows selected source and Actor-pack counts.
- Use **Configure Sources** and confirm it opens the same Crafting Core settings screen.
- Run Scan and confirm performance remains comparable to v0.0.7.

## 3. Search focus regression

- Click the Harvest Profile search field.
- Type `skeleton` at normal speed.
- Confirm the cursor does not jump and the Scanner does not rerender on each keypress.
- Press Enter and confirm the filter applies.
- Repeat with `death knight`, applying via the magnifying-glass button.
- Type another query and Tab/click away; confirm blur applies the query.
- Confirm Clear resets the filter.

## 4. Undead classification regression

Reanalyze or rescan representative creatures.

Expected:

- **Ghost / Specter / Wraith / Banshee**: `incorporeal`; no `bone` or `flesh`.
- **Skeleton**: `bone`; no `flesh`/`blood`.
- **Demilich**: bone-focused; not automatically incorporeal merely because of magical abilities.
- **Lich**: physical fallback (`bone`/`flesh`, and physical-remains baseline) unless the Actor has a truly structural incorporeal feature.
- **Mummy Lord**: physical fallback; not spirit-only because of spell names.
- **Death Knight / Undead Knight**: physical fallback; spectral/spirit spell names must not classify them as incorporeal.

Open **Why these tags?** and confirm incidental spectral spell language is explicitly treated as weak evidence.

## 5. Undead material completeness

- Run **Materials → Create / Sync Materials** once for the v0.0.8 internal catalog.
- Confirm **Funerary Dust** exists as Common Undead material.
- Confirm **Necrotic Essence** exists as Uncommon Undead material.
- Confirm the built-in catalog contains 121 records.
- Reanalyze a Skeleton: it should normally be able to fill four coherent automatic slots with bone/generic Undead materials.
- Reanalyze Lich/Mummy Lord/Death Knight: they should normally fill four coherent slots when the catalog supports them.
- Reanalyze a true Ghost-like Actor: with the v0.0.8 fallback materials it should normally reach four coherent slots without receiving fake bone/flesh.

## 6. Generic Analyzer checks

- **Stone Golem / stone Construct**: mineral/stone evidence; do not assume metal merely from Construct type.
- **Iron/clockwork Construct**: metal/mechanical when source data supports it.
- **Flesh Golem**: flesh/blood/bone when source identity supports it.
- **Ooze**: amorphous baseline.
- **Plant**: plant baseline.
- A creature with a spell containing `spirit`, `spectral`, `phantom`, or similar should not have anatomy changed solely by that spell name.

## 7. Harvest Profile behavior

- Edit an automatic slot, chance, quantity, and anatomy tags; Save.
- Add a Pinpoint Override; Save.
- Reanalyze the Actor.
- Confirm automatic slots/anatomy rebuild from source data and Pinpoint Overrides remain intact.
- Confirm source Actor and source Compendium remain untouched.

## 8. Recipe Builder layout

- Open Crafting Core with one Recipe and with several Recipes.
- Confirm the Recipes area is visibly wider than v0.0.7 and names are easier to read.
- Confirm the Recipe list receives usable vertical space and does not show unnecessary scrolling for a single entry.

## 9. Regression

- Generate Creature Harvest manually and verify preview-first behavior remains: Generate does not create Items; Create Loot Folder materializes the accepted preview.
- Generate Environment Gathering and confirm it still works.
- Learn and craft one existing Recipe to ensure Scanner/settings changes did not affect the crafting core.
