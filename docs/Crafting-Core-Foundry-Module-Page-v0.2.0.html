Crafting Core (DnD 5e)

Crafting Core is a GM-authoritative crafting, harvesting, material, and resource-generation framework for Foundry Virtual Tabletop, built specifically for D&D 5e 5.3.3.

Crafting Core on GitHub

v0.2.0 - Curated Culinary Library

v0.2.0 keeps the live-validated v0.1.0 crafting foundation intact and adds the first official Crafting Core Curated Content library.

  • 15 Common Curated Culinary Recipes: 5 Dwarven, 5 Elven, and 5 Common Cuisine.
  • Crafting Core - Products: a new private Compendium with 15 ready-to-distribute food Consumables.
  • 15 matching Recipe Knowledge Sources in Crafting Core - Learn Sources.
  • Hearty Meals grant 5 Temporary Hit Points.
  • Energizing Meals grant +5 ft Walking Speed until the next Long Rest.
  • Complete Meals provide both benefits.
  • Supplier-ready metadata includes category, culture, rarity, meal type, stable Product ID, and stable Recipe ID.
  • Three native Foundry icon candidates are curated for every Product; no artwork is bundled.

DnD 5e Item Creator Integration

The base Crafting Core module remains independent. The official Curated Culinary library requires DnD 5e Item Creator 0.7.1+ to install/synchronize and uses Item Creator's normal Consumable runtime for persistent meal effects and Long Rest cleanup.

Stable Crafting Foundation

  • Private Recipe Drafts keep edits separate from the live published version.
  • Knowledge Base manages the authoritative Crafting Core - Learn Sources Compendium.
  • Publish / Update Published Source deliberately promotes Draft changes.
  • Learn / Unlearn / Unpublish use stable Recipe identity and verified Actor cleanup.
  • Timed Crafting and Crafting Projects support simple crafts and multi-rest project workflows.
  • Frozen Project snapshots protect work already in progress from later Recipe edits.
  • 229 curated Materials, Creature Scanner, Harvest Profiles, Token Harvest, Environment Gathering, Game Hunt, and optional Item Piles output.

Compatibility

  • Foundry VTT: minimum 14, verified 14.365
  • D&D 5e: 5.3.3
  • DnD 5e Item Creator: 0.7.1+ recommended; required for Curated Culinary content
  • Item Piles: optional
