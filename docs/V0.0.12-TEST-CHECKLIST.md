# Crafting Core v0.0.12 — Item Piles Cleanup Hotfix Test Checklist

## Prerequisites
- Foundry VTT 14.365.
- D&D5e 5.3.3.
- Item Piles active.
- Crafting Core materials synchronized.
- Fresh dead Tokens from scanned/reanalyzed Actors.

## 1. Reproduce the v0.0.11 regression case
1. Use a fresh dead **Bugbear Warrior** that contains stat-block Items such as `Abduct` plus ordinary gear.
2. Set **Existing NPC Loot → Normalize from Compendiums**.
3. Generate Harvest from the Token HUD bag icon.
4. Confirm there is no `Could not find item with id "mmAbduct..."` error.
5. Confirm the corpse becomes an Item Pile.
6. Confirm Crafting Core Harvest materials are present.

## 2. Bullywug regression case
1. Use a fresh dead **Bullywug Warrior** containing `Amphibious` and ordinary gear.
2. Generate Harvest in Normalize mode.
3. Confirm there is no `Could not find item with id "mmAmphibious..."` error.
4. Confirm generated Crafting Core materials are present.

## 3. Remove All
1. Set **Existing NPC Loot → Remove All Existing Items**.
2. Use fresh Bugbear/Bullywug Tokens.
3. Generate Harvest.
4. Confirm transferable existing NPC loot is removed.
5. Confirm filtered stat-block Features do not cause errors.
6. Confirm only generated Crafting Core loot is exposed to players.

## 4. Normalize from Compendiums
1. Configure PHB 2024 first and SRD 5.2 second.
2. Use an NPC with a modified ordinary weapon (for example a stat-block Light Hammer).
3. Generate Harvest.
4. Confirm the transferable NPC weapon is removed.
5. Confirm its safe base Compendium replacement is added.
6. Confirm non-transferable/filtered Features are not processed as removal IDs.

## 5. Fail-soft Harvest protection
1. If possible, force or simulate a cleanup failure after Item Piles conversion.
2. Confirm the console logs a Crafting Core cleanup warning.
3. Confirm Harvest / Essence / Pinpoint materials are still injected into the pile.
4. Confirm normalized replacement gear is not duplicated after a failed cleanup.

## 6. Keep All regression
1. Set **Keep All Existing Items**.
2. Generate Harvest from a fresh eligible corpse.
3. Confirm v0.0.10-style behavior remains unchanged and generated materials are added.

## 7. Regression
- Creature Scanner profile resolution remains unchanged.
- Scanner list scrolling remains fixed from v0.0.11.
- Manual Essence generation remains unchanged.
- Actor Essence generation remains unchanged.
- Pinpoint materials remain separate.
- Multi-token Harvest still creates one pile per eligible corpse.
- Per-Token anti-reroll metadata still prevents a second Harvest.
