Crafting Core (DnD 5e)

Crafting Core is a GM-authoritative crafting, harvesting, and material framework for Foundry Virtual Tabletop, built specifically for D&D 5e.

Build simple timed crafts or persistent multi-rest Crafting Projects, publish learnable Recipe/Formula/Blueprint/Manual Items, control what players can see, harvest creatures, generate environmental resources, and keep the entire material flow inside native Foundry and D&D 5e documents.

v0.1.0 Stable Foundation

  • Private Recipe Drafts keep GM edits separate from the live published version.
  • Knowledge Base manages the authoritative Crafting Core - Learn Sources Compendium.
  • Publish / Update Published Source deliberately promotes Draft changes to the live Compendium source.
  • Learn Recipe works through direct Compendium distribution or normal World Item workflows.
  • Unlearn removes Character knowledge without unpublishing the global source.
  • Unpublish removes the authoritative source and makes Characters forget it, while already-started Projects preserve their frozen snapshots.
  • Stable Recipe identity prevents duplicate learning from multiple physical copies.

Crafting

  • GM-authored Recipes using normal D&D 5e Items as ingredients and outputs.
  • Timed Crafting for simple second-based jobs.
  • Crafting Projects with reserved materials, Work Periods, Short/Long Rest cadence, Progress Checks, configurable failure consequences, Extra Effort, and Final Crafting Checks.
  • Frozen Project snapshots protect work already in progress from later Recipe edits.
  • Player Visibility controls ingredients, proficiencies, DCs, progress, consequences, descriptions, and other Recipe information.

Harvesting & Materials

  • 229 curated built-in materials stored as native D&D 5e Loot / Trade Good Items.
  • Creature Scanner analyzes configured Actor sources without modifying the source Actors.
  • Harvest Profiles use rarity pools, separate Essence generation, and GM-authored Pinpoint Overrides.
  • Token Harvest supports configurable handling of existing NPC gear.
  • Generate Materials supports Manual Creature Harvest, Environment Gathering, and Game Hunt.
  • Preview-first generation can create World loot or optional Hidden Item Piles.

Compatibility

  • Foundry VTT: minimum 14, verified 14.365
  • D&D 5e: 5.3.3
  • Item Piles: optional
