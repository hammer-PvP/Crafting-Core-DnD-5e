# Crafting Core v0.0.19c — Live Test Checklist

This build is a catalog / Materials UI expansion on top of the stable v0.0.19 Project line. Project/Harvest logic should behave exactly as v0.0.19b.

## 1. Upgrade and synchronization

- [ ] Install v0.0.19c over a v0.0.19b world.
- [ ] Open **Crafting Core → Materials**.
- [ ] Click **Create / Sync Materials** once.
- [ ] Confirm the private `Crafting Core — Materials` pack contains all new managed Items and old custom/GM-edited materials remain intact.
- [ ] Confirm existing GM-selected material icons are preserved.

Expected built-in catalog: **202 managed materials**.

## 2. Materials search — human typing regression

- [ ] Put the Materials window somewhere in the middle of the catalog and type `salts` slowly.
- [ ] Type `undead` slowly.
- [ ] Type a partial material name, delete characters, and type again.
- [ ] Confirm focus and caret never leave the search field.
- [ ] Confirm the Materials window does not jump to the top while typing.
- [ ] Confirm open/closed group state is not reset by each keypress.
- [ ] Confirm the visible-count header and per-group counts update while searching.
- [ ] Confirm search can match group metadata such as `undead`, tags, and biome words in addition to the displayed material name.

Dropdown Family/Nature/Rarity filters may still rerender intentionally when changed.
